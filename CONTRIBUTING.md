# Contributing to Todo

Thank you for your interest in contributing to our little todo app! We're excited to have you onboard.

## How to Contribute
1. **Fork the repository** and clone it locally.
2. Create a new branch for your changes: `git checkout -b feature/your-feature`.
3. Make your changes in the newly created branch.
4. Commit your changes with a clear commit message: `git commit -m 'Added feature X'`.
5. Push to your fork and **submit a pull request** to the main repository.

## Code Style
- Follow existing code style, including indentation and naming conventions.
- Ensure your code passes all tests before submitting a pull request.

## Issues
If you find any issues or have suggestions for improvements, please [open an issue](https://github.com/username/Todo/issues) in the repository.

We look forward to your contributions!
